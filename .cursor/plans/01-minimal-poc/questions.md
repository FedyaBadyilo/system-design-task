# Вопросы — минимальный PoC обработки тикетов

## Краткое описание задачи

Нужно реализовать локально запускаемый вертикальный срез: принять mock-тикет,
очистить PII, классифицировать тему и риск, принять policy-решение, найти знания,
сформировать ответ либо передать тикет оператору и сохранить аудит. Архитектурные
границы уже зафиксированы; вопросы ниже касаются только решений, которые заметно
влияют на реализацию и честность демонстрации PoC.

## Приоритетные вопросы

### 1. Какую роль должен играть реальный вызов Polza AI?

**Почему это важно:** определяет основной режим demo, адаптер генерации и
воспроизводимость проверки без ключа.

**Тип ответа:** один вариант

- [x] Опциональный реальный режим через Polza AI, детерминированный генератор по умолчанию и в тестах
- [ ] Реальный вызов Polza AI по умолчанию, детерминированная замена только для тестов и fallback
- [ ] Пока реализовать только интерфейс и детерминированную замену, Polza AI подключить позже
- [ ] Другое: ...

**Финальный ответ:** если в .env будут записи данные и апи доступен, то реальный вызов. кстати это именно я буду использовать polza ai, а так реальный взов должен быть в целом openai-совместимым (ну и скорее всего vllm совместимым)

---

### 2. Какой API-контракт предоставляет Polza AI? — выяснено

**Почему это важно:** без этого нельзя корректно выбрать клиент и формат
структурированного ответа; секреты при этом останутся только в `.env`.

**Тип ответа:** один вариант

- [x] OpenAI-compatible API; модель задаётся конфигурацией
- [ ] Собственный API; я дам ссылку на документацию или пример запроса
- [ ] Пока неизвестно — заложить нейтральный интерфейс провайдера без реального клиента
- [ ] Другое: ...

**Финальный ответ:** официальный API совместим с OpenAI Chat Completions:
`base_url=https://polza.ai/api/v1`, Bearer API key, список моделей доступен через
`GET /models`. Поддерживается `response_format` с `json_schema`. В PoC
провайдер и модель задаются через `.env`, без привязки доменной логики к Polza AI.

---

### 3. Как поступить с отсутствием реального размеченного датасета для классификатора?

**Почему это важно:** архитектура фиксирует `TF-IDF + Logistic Regression`, но
качество и confidence нельзя честно демонстрировать без данных.

**Тип ответа:** один вариант

- [ ] Реализовать настоящий pipeline на небольшом явно синтетическом корпусе в репозитории; не заявлять его качество
- [x] Использовать детерминированный классификатор-замену, а `TF-IDF + Logistic Regression` оставить только целевым baseline
- [ ] Я предоставлю обезличенный набор примеров для PoC
- [ ] Другое: ...

**Финальный ответ:** можно тупо мок по какому-то правилу (условно вхождение того или иного слова в тексте)

---

### 4. Что считать успешным действием для безопасного тикета в PoC?

**Почему это важно:** реальной helpdesk-интеграции нет, поэтому нужно точно
разделить сформированное решение и внешний side effect.

**Тип ответа:** один вариант

- [x] Сформировать `AUTO_REPLY_READY`, текст ответа и audit; отправку и закрытие только имитировать
- [ ] Всегда формировать `DRAFT_FOR_REVIEW`, даже для безопасного happy path
- [ ] Добавить локальный mock helpdesk adapter, который имитирует отправку и закрытие
- [ ] Другое: ...

**Финальный ответ:** PoC формирует payload ответа, который в целевой системе был
бы отправлен в helpdesk, но не имитирует саму отправку или закрытие тикета.

---

### 5. Насколько реально воспроизводить реляционный аудит из архитектуры?

**Почему это важно:** это определяет, демонстрируем ли мы append-only решения,
идемпотентность и evidence как работающую часть PoC или только как контракт.

**Тип ответа:** один вариант

- [x] SQLite с минимальной нормализованной схемой из `architecture.md`
- [ ] Упрощённый JSON-аудит, а полную реляционную схему оставить целевой архитектуре
- [ ] In-memory repository с печатью audit-записи в demo
- [ ] Другое: ...

**Финальный ответ:** SQLite-файл создаётся как локальный runtime-артефакт в
игнорируемом каталоге `.data/`, а путь задаётся конфигурацией. Контейнеризация
не входит в PoC; если она появится позже, этот же каталог можно подключить как
volume без изменения приложения.
